🕵️‍♂️ Imposter
A lightweight, web-based social deduction game built with a Python, HTML, CSS, and JavaScript.

🎮 How It Works
Inspired by classic party deduction games, every player receives a shared secret prompt, except for one hidden Imposter who receives a completely different or opposite prompt. Players discuss the topic under a strict countdown timer and then vote on who they believe the Imposter is.
